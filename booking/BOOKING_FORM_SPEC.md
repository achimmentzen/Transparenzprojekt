# Public Booking Form Specification

The public form should collect only the minimum information required to initiate an appointment.

## Required

- Name
- E-mail address
- Confirmation of age 18+
- Requested date/time
- Duration
- Offer category
- Agreement to the current consent/terms version

## Offer categories

- Performance / observation
- Body-related appointment within a predefined framework
- Individual/intimate framework

The third category may be automatically accepted as an **organisational appointment** only when all technical conditions are met. The actual consent for any concrete interaction remains current and revocable.

## Double opt-in

The requester must confirm the e-mail address through a single-use confirmation link before the appointment can reach CONFIRMED.

## Privacy

Do not submit intimate descriptions through a public GitHub issue, repository file, URL query parameter or client-side GitHub token.
