# Achim Mentzen – Living Sculpture / Transparenzprojekt

**Living Sculpture / Transparenzprojekt** ist ein öffentlich dokumentiertes Kunst- und Performanceprojekt von **Achim Mentzen**.

Das Projekt untersucht Körper, Nacktheit, Scham, Öffentlichkeit, Selbstbestimmung und freiwillig delegierten Entscheidungsspielraum. Ein besonderer Schwerpunkt liegt auf der Frage, wie weit künstlerische Fremdgestaltung gehen kann, wenn sie zuvor bewusst und freiwillig als Teil des Projektrahmens vereinbart wurde.
