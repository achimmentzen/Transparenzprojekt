## Purpose

The project uses redundant public documentation: Git history, independent mirrors, archives, distributed storage and, where technically available, a lawful Tor mirror.

## Layers

1. GitHub source — versioned canonical project material.
2. Independent Internet mirror — separately hosted static copy.
3. Archive or content-addressed copy — when an authorized service is available.
4. Tor mirror — separate `.onion` access path when an authorized host exists.

No layer is claimed to exist until its actual public address, CID or deployment record is entered.

## Integrity

Never invent mirror URLs, IPFS CIDs, onion addresses, media coverage, institutional partnerships or publication confirmations.

Every real publication should be logged with date, platform, URL and source version.

## Non-deletion / history

Project documentation should be maintained additively. Corrections should create new versions or commits instead of destroying historical evidence. Git history remains the preferred record of superseded project states.

This does not create a technical guarantee against deletion by GitHub, hosting providers, archives or third parties.
