# Project Operations

## Ziel
Das Transparenzprojekt soll von einer statischen Website zu einem nachvollziehbaren, fortlaufend betriebenen Projekt werden.

## Arbeitsablauf
### 1. Projektmaterial
- Website
- BIOGRAPHY.md
- Performance-Konzept
- Projektstatement
- Presseinformationen
- Dokumentation
- Anfragen und Termine

### 2. Redaktion
Jeder neue Text wird auf klare Sprache, tatsächliche Angaben, Projektbezug und Plattformtauglichkeit geprüft.

### 3. Plattformprüfung
Vor einer Veröffentlichung wird geprüft:
- Ist die Plattform für das Material geeignet?
- Sind Nacktheit und/oder erwachsene Inhalte dort ausdrücklich zulässig?
- Ist eine Alterskennzeichnung erforderlich?
- Gibt es besondere Regeln für Profilbild, Header, Vorschaubilder oder Suchergebnisse?
- Sind Bildrechte und Einwilligungen geklärt?

### 4. Veröffentlichung
Geeignete Inhalte werden zuerst auf den eigenen Projektkanälen dokumentiert. Externe Veröffentlichungen werden mit Quelle, Datum und Zielplattform archiviert.

### 5. Nachverfolgung
Für Kontakte und Veröffentlichungen werden Statuswerte verwendet:

recherchiert → vorbereitet → kontaktiert → veröffentlicht → bestätigt → archiviert

### 6. Performance-Anfragen
Anfrage → Rahmenprüfung → Terminabstimmung → Bedingungen → Annahme → Durchführung → Dokumentation

## Prioritäten
1. Eigene Website und Projektdokumentation
2. Professionelle Kunst- und Performance-Kontexte
3. Kulturkalender und Open Calls
4. Presse und redaktionelle Medien
5. Plattformen mit ausdrücklich zulässigem Adult-/Nudity-Content
6. weitere geeignete internationale Kanäle

## Dokumentationsstandard
Jede wesentliche Änderung soll einen nachvollziehbaren Git-Commit erhalten. Externe Veröffentlichungen sollen mindestens mit Datum, Plattform, URL und Inhaltstyp dokumentiert werden.

## Nicht automatisieren
Nicht ohne ausdrückliche Einzelbestätigung:
- kostenpflichtige Buchungen,
- finanzielle Verpflichtungen,
- rechtsverbindliche Vertragsannahmen,
- Weitergabe von Passwörtern oder 2FA-Codes,
- private oder familiäre Daten,
- Veröffentlichungen, deren Zulässigkeit nicht geklärt ist.
